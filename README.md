# 🌊 RiveraQuest Safaris

**Discover Extraordinary River & Marine Safaris**

RiveraQuest Safaris is a web-based safari booking and management system designed to simplify river and marine safari experiences. The platform allows customers to explore safari packages, manage bookings, and access services through a user-friendly interface, while staff members can manage different operational activities through role-based dashboards.

## ✨ Features

- 🏝️ **Safari Packages** – Explore available river and marine safari experiences.
- 📅 **Booking Management** – Manage safari reservations and booking details.
- 👤 **Customer Portal** – Access customer features, booking history, and reviews.
- 🎫 **Booking Validation** – Support booking verification and receipt management.
- 🚤 **Fleet Management** – Manage vessel-related information and operational activities.
- 📢 **Marketing Management** – Support promotional campaigns, vouchers, and customer feedback.
- 🔐 **Role-Based Access** – Provide separate dashboards and access for different staff roles.
- ⭐ **Reviews & Feedback** – Allow customers to share their safari experiences.

## 👥 User Roles

The system supports different user roles to organize safari operations:

- **Tourist / Customer** – Browse packages, make bookings, and manage booking history.
- **Tourist Desk Officer** – Handle customer bookings, validate bookings, and manage receipts.
- **Fleet Manager** – Manage vessel information and fleet-related operations.
- **Marketing Officer** – Manage promotional campaigns, vouchers, and customer feedback.
- **System Administrator** – Manage system operations and administrative functions.

## 🛠️ Technologies Used

The project uses web development technologies and a database to support its functionality.

- **Frontend:** HTML, CSS, JavaScript, Tailwind CSS
- **Backend:** Java, Spring Boot
- **Database:** Microsoft SQL Server
- **Database Management:** SQL Server Management Studio (SSMS)
- **Version Control:** Git and GitHub


## 🚀 Getting Started

Follow these steps to set up the project locally.

### Prerequisites

Make sure you have the following installed:

- Java Development Kit (JDK)
- Maven
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- Git
- An IDE such as IntelliJ IDEA or Visual Studio Code

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/jalinawaruna70-debug/RiveraQuest_Safaris.git
```

**2. Navigate to the project directory**

```bash
cd RiveraQuest_Safaris
```

**3. Configure the database**

- Create a database in Microsoft SQL Server.
- Execute your project's database scripts, if provided.
- Update the database connection settings in the application configuration file.
- Configure your local database credentials.

**4. Run the application**

If the project uses Maven and Spring Boot, run:

```bash
mvn spring-boot:run
```

Alternatively, run the main Spring Boot application class through your IDE.

**5. Open the application**

Open the local URL configured for your application in your web browser.

For a standard Spring Boot application, the default address is:

```text
http://localhost:8080
```
